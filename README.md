# Agent-native Accounting

A public informational proposal for a New Zealand accounting service built around customer-owned agents and accountable human review.

**Status: in development.** This is not an open accounting practice. No client records, instructions, filings or payments are accepted here. The descriptive title is not a company-registration or professional-accreditation claim.

The no-build static site is in `docs/`. GitHub Pages publishes that directory from `main`; `.nojekyll` preserves the static assets. The JSON profile describes intended scope only, with no live endpoints or binding offer.

No client data, private research, analytics code or external asset libraries are included. GitHub, as hosting provider, processes visitor connection data under its privacy statement.

Operating the commercial service or collecting sensitive data is outside this repository and requires appropriate hosting, an identified accountable operator and separately established authority.
